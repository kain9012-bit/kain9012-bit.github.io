02

먼저 알아 둘 말

이 문서에 계속 나오는 말 일곱 가지. 비유로 먼저 이해하고 넘어가기.

모션그래픽

글자·도형·숫자·그림을 움직여 내용을 설명하는 영상. 사람이 나오지 않는 설명영상의 대부분이 여기에 해당.

파일을 만들고 실행하는 AI

질문에 답만 하는 AI가 아니라, 내 PC 폴더에 파일을 만들고 프로그램을 직접 돌리는 AI. 이번 제작은 Claude 데스크톱 앱에서 작업 폴더를 연결해 진행.

비유 — 조언만 하는 컨설턴트 vs 손을 움직여 만들어 주는 작업자
TTS (글 → 음성)

글을 넣으면 사람 목소리로 읽어 주는 기술. Text to Speech의 줄임말.

피쉬오디오 (Fish Audio)

TTS 서비스 이름. 목소리를 고르거나 내 목소리를 복제한 뒤 글을 넣으면 그 목소리로 읽은 음성 파일을 만들어 줌. 한국어 화면 지원.

목소리 모델

특정 사람의 목소리 특징을 담아 둔 '목소리 견본'. 고유 번호(32자리)로 구분. 남이 공개한 목소리를 쓰거나 내 녹음으로 직접 만들 수 있음.

비유 — 성우 명부의 성우 한 명, 번호는 그 성우의 사원번호
API

사람이 홈페이지 버튼을 누르는 대신, 프로그램이 서비스에 직접 주문하는 통로. AI가 대본 수십 문장을 한꺼번에 주문할 때 사용.

비유 — 매장 창구(홈페이지) 옆에 따로 있는 단체 주문 전용 창구
API 키

그 통로를 '내 계정으로' 쓰게 해 주는 비밀 열쇠. sk-fish-로 시작하는 긴 글자. 남이 알면 내 계정으로 마음대로 쓸 수 있어 비밀번호처럼 관리.

비유 — 내 이름으로 주문할 수 있는 법인카드
'모델'이 두 번 나오는 이유 — 피쉬오디오에서 '모델'은 두 가지 뜻. ① 목소리 모델: 누구 목소리로 읽을지 (예: 「신뢰감 남자 광고 아나운서」) ② 음성 생성 모델: 어떤 엔진으로 만들지 (예: S2.1 Pro). 이 문서에서 그냥 '모델'이라고 하면 ①.

06

준비물

사람이 챙길 것 다섯 가지. 나머지 프로그램 설치·실행은 AI 쪽에서 처리.

① 파일을 만들고 실행하는 AI
  • 대화만 하는 AI로는 영상 파일까지 못 만듦
  • 이번 제작: Claude 데스크톱 앱 + 작업 폴더 연결 → 결과물이 내 폴더에 바로 저장
② 참고영상
  • 마음에 드는 모션그래픽 영상 몇 편을 한 폴더에
  • "먼저 분석하고 어떤 기법을 가져올지 말해 줘"
③ 사실 자료
  • 숫자·사례·날짜의 출처 문서
  • 근거 없는 숫자는 영상에 넣지 않기
④ 피쉬오디오 계정과 API 키
  • 가입 → 목소리 고르기 → 키 발급
  • 처음 한 번만, 화면 따라 하기는 8장
⑤ 유튜브 계정
  • 강의안에 넣을 영상 업로드용
  • 파일로 넣는 것보다 강의안이 가볍고 어디서나 재생
07

단계별 방법

단계마다 실제로 쓴 요청 방식. 요청문은 [복사] 후 ○○만 바꿔 사용.

01

의도·자료 정리

  • 대상·길이·위치 — 누가 보는지, 몇 분, 강의안 어디에
  • 사실 자료 — 숫자와 사례의 출처를 함께 전달
  • 참고영상 — 폴더 위치를 알려 주고 먼저 분석 요청
강의에 넣을 2~3분짜리 설명 영상을 만들고 싶어. 보는 사람은 ○○이고, 강의안 ○쪽 뒤에 넣을 거야. 꼭 들어가야 할 내용과 출처는 첨부한 자료에 있어. 참고영상은 ○○ 폴더에 있으니 먼저 살펴보고 어떤 기법을 가져올지 알려 줘. 영상은 아직 만들지 말고 시나리오부터 줘.
02

시나리오 먼저

  • 장면 표 — 장면마다 시간, 화면에 나올 것, 나레이션 문장
  • 정할 것 목록 — 길이, 말투, 1인칭·3인칭, 실제 화면 사용 여부 등
  • 확정 뒤 제작 — 화면부터 만들면 고칠 것이 훨씬 많아짐
장면마다 시간, 화면에 나올 것, 나레이션 문장을 표로 정리해 줘. 내가 정해야 할 것은 마지막에 따로 모아 줘. 사실이 아닌 연출이 들어가면 그것도 표시해 줘.
실제 사례 — 영상 4 시나리오에서 정한 것: 길이 그대로 · 거친 말은 순화 · 나레이션은 1인칭 · 업무 시스템은 모의 화면 · 마지막 문구 그대로
03

무음 초안

  • 소리 없이 먼저 — 화면이 확정돼야 나레이션도 확정
  • 스틸 미리 보기 — 화면이 가장 복잡한 순간 몇 장을 먼저 받아 확인
  • 자막은 기본 — 대본이 화면 아래 자막으로 함께 나오게
시나리오대로 먼저 소리 없이 영상을 만들어 줘. 만들기 전에 화면이 가장 복잡한 장면 몇 개를 캡처해서 보여 줘. 글자가 겹치거나 잘리는 곳이 없는지도 확인해 줘.
04

화면 피드백

  • 위치 — "1분 14초부터"처럼 시각으로
  • 문제 — 무엇이 이상한지
  • 이유 — 왜 이상한지, 보는 사람이 어떻게 받아들일지

실제로 한 수정 요청은 9장에 정리.

05

나레이션

  • 피쉬오디오 연결 — 대본 전체를 문장 단위로 한 번에 생성
  • 화면 시간 자동 조정 — 문장 길이에 맞춰 장면 길이와 자막 위치를 다시 계산

준비부터 요청까지 8장에 화면과 함께 정리.

06

배경음악·합치기

  • 저작권 걱정 없는 음악 — 음원을 내려받지 않고 AI가 코드로 직접 작곡·합성 (영상 1)
  • 목소리 우선 — 나레이션이 나오는 동안 음악 소리 자동으로 낮춤
  • 음량 통일 — 여러 영상의 소리 크기를 같은 기준으로
  • 선택 사항 — 설명 위주 영상은 나레이션만으로도 충분 (영상 2~4)
저작권 걱정 없는 배경음악을 직접 만들어서 넣어 줘. 장면이 바뀌는 순간에 맞춰 분위기가 바뀌면 좋겠고, 나레이션이 나올 때는 음악 소리를 줄여 줘.
07

유튜브·강의안

  • 유튜브 업로드 — 공개 범위는 목적에 맞게 선택
  • 강의안 삽입 — 주소만 주면 전체화면 영상 슬라이드로 삽입, 슬라이드를 넘기면 자동 정지
  • 위치 상의 — 강의 흐름에서 어디가 맞을지 AI에게 이유와 함께 추천받기
유튜브 주소는 ○○야. 강의안 어디에 넣는 게 가장 좋을지 이유와 함께 추천해 주고, 정하면 그 위치에 전체화면으로 넣어 줘.
08

피쉬오디오 따라 하기

처음 한 번만 하면 되는 준비: 가입 → 목소리 고르기 → API 키 발급 → AI에게 연결.
화면은 2026. 11. 11. 기준, 그림을 누르면 크게 보기.

1피쉬오디오 알아보기2가입·한국어 화면3목소리 고르기4홈페이지에서 써 보기5API 키 발급6AI에게 연결

8-1. 피쉬오디오 알아보기

  • 무엇 — 글을 사람 목소리로 읽어 주는 음성 생성 서비스
  • 할 수 있는 일 — 텍스트 음성 변환(글 → 음성) · 음성 복제(내 목소리 견본 만들기) · 음성 인식(음성 → 글)
  • 이번에 쓴 기능 — 텍스트 음성 변환 하나

8-2. 가입·한국어 화면

  • 가입 — fish.audio/ko 접속 → 오른쪽 위 버튼 → 화면 안내에 따라 가입
  • 한국어 화면 — 주소에 /ko/가 들어가면 메뉴가 한국어로 표시. 이 문서의 화면도 모두 한국어
  • 요금제 — 가입하면 무료(Free) 계정으로 시작. 이번 영상 4편도 무료 계정으로 제작

8-3. 목소리 고르기 — 두 가지 길

A. 공개 목소리 쓰기 이번 영상 4편
  • 다른 사용자가 만들어 공개한 목소리 중에서 선택
  • 녹음 없이 바로 사용, 성우 같은 목소리도 많음
B. 내 목소리 복제하기
  • 내 녹음 10초 이상으로 나만의 목소리 모델 생성
  • 강의자 본인 목소리로 나레이션 가능

A. 공개 목소리 쓰기

목소리 번호 찾기 — 이 화면의 주소창 끝 32자리가 목소리 모델 번호.
fish.audio/ko/app/m/a92ba61d943e467b8f809b87b3d51b1a/
AI에게는 이 주소를 통째로 알려 주면 충분.

B. 내 목소리 복제하기

  • 녹음 요령 — 조용한 곳, 평소 강의하는 말투·속도, 30초 안팎
  • 공개 범위 — 내 목소리 모델은 비공개로 두기

8-4. 홈페이지에서 써 보기 (선택)

API 없이도 홈페이지에서 바로 음성을 만들 수 있음. 목소리가 마음에 드는지 확인하는 용도로 추천.

영상 나레이션에는 불편 — 대본이 수십 문장이면 붙여 넣기·생성·내려받기·파일 이름 정리를 문장마다 반복. 그래서 다음 단계의 API 연결이 필요.

8-5. API 키 발급

1키 복사생성 후 화면에 나온 sk-fish-… 키 전체를 복사
2메모장에 저장메모장에 키만 한 줄로 붙여 넣고 fish_key.txt로 저장
3작업 폴더에 두기AI와 연결한 작업 폴더 안에 저장 → AI는 파일에서만 읽음
키가 새어 나갔다면 — 'API 키' 목록 오른쪽 휴지통 아이콘으로 그 키 삭제 → 새로 생성 → fish_key.txt 내용 교체. 대화창·메신저·공유 폴더에 키를 올리지 않기.

8-6. AI에게 연결

나레이션은 피쉬오디오로 넣어 줘. 목소리는 ○○(목소리 상세 화면 주소)이고, API 키는 ○○ 폴더의 fish_key.txt에 넣어 뒀어. 키는 화면에 보여 주지 말고 파일에서만 읽어 줘. 숫자와 영어는 읽는 대로 바꿔서 만들고, 문장 길이에 맞춰 화면과 자막 시간을 맞춰 줘.

요청하면 AI가 하는 일:

1대본을 문장별로자막용·낭독용 구분
2문장마다 주문API로 음성 생성
3앞뒤 무음 자르기문장 사이 간격 일정
4길이 재기문장별 초 단위
5화면 시간 맞춤장면·자막 재계산
6합치기영상 + 음성

자주 막히는 곳

막혔을 때 AI에게 이렇게 말하면 해결되는 경우가 대부분.

AI가 API 키를 못 읽는다고 할 때
  • 파일 내용 — fish_key.txt 첫 줄에 키만 있는지 확인 (주소·메모를 같이 적었다면 다른 줄로)
  • 파일 위치 — AI와 연결한 작업 폴더 안에 있는지 확인
  • 키 상태 — 'API 키' 목록에서 상태가 '활성화'인지, 만료되지 않았는지
발음이 어색하거나 끊어 읽기가 이상할 때
  • 낭독용 문장 고치기 — 숫자·영어를 한글로, 끊을 곳에 쉼표
  • 바뀐 문장만 다시 — "○번째 문장만 다시 만들어 줘"
소리와 화면·자막이 어긋날 때
  • "문장 길이를 다시 재서 장면 시간과 자막을 맞춰 줘"
  • 나레이션을 바꾼 뒤에는 영상도 다시 뽑아야 맞음
목소리를 바꾸고 싶을 때
  • 새 목소리 상세 화면 주소를 알려 주고 "이 목소리로 전체 다시 만들어 줘"
  • 문장 길이가 달라지므로 화면 시간도 다시 맞춤
생성이 실패하거나 느릴 때
  • 동시 요청 제한 — 한꺼번에 너무 많이 보내면 거절됨. "한 문장씩 순서대로, 실패하면 잠시 뒤 다시"
  • 무료 정책 변경 — 무료 모델이 끝났다면 개발자 화면의 안내 확인
고쳤다는데 영상이 그대로일 때
  • "저장된 파일을 직접 다시 열어서 바뀐 부분이 들어갔는지 확인해 줘"
  • 같은 이름 파일을 덮어쓸 때 생기는 일. 저장 뒤 확인까지 요청
11

지켜야 할 것

영상은 한 번 퍼지면 고치기 어려움. 올리기 전 아래 항목 점검.

  • 사실만 — 지어낸 숫자·사례 금지. 연출이 들어간 화면에는 '연출' 표기
  • 개인정보 — 실제 명단 대신 가상 명단, 업무 시스템은 모의 화면, 화면 코드·캡처의 개인정보는 흐림 처리
  • 참고영상 — 기법만 참고, 그대로 베끼지 않기
  • 목소리 — 복제는 본인 목소리만. 공개 목소리는 피쉬오디오 이용 조건 확인 후 사용
  • API 키 — 대화창에 붙여 넣지 않기, 자료를 나눠 줄 때 키 파일 빼기
  • 이미지·음악 — 출처 불분명한 이미지·음원 쓰지 않기, 필요하면 직접 그리고 직접 합성
  • 최종 파일 확인 — 수정 뒤 저장된 파일이 정말 새 버전인지 직접 재생해 확인

요청문 모음

순서대로 쓰면 한 편 완성. ○○만 바꿔 사용.

강의에 넣을 2~3분짜리 설명 영상을 만들고 싶어. 보는 사람은 ○○이고, 강의안 ○쪽 뒤에 넣을 거야. 꼭 들어가야 할 내용과 출처는 첨부한 자료에 있어. 참고영상은 ○○ 폴더에 있으니 먼저 살펴보고 어떤 기법을 가져올지 알려 줘. 영상은 아직 만들지 말고 시나리오부터 줘.
장면마다 시간, 화면에 나올 것, 나레이션 문장을 표로 정리해 줘. 내가 정해야 할 것은 마지막에 따로 모아 줘. 사실이 아닌 연출이 들어가면 그것도 표시해 줘.
시나리오대로 먼저 소리 없이 영상을 만들어 줘. 만들기 전에 화면이 가장 복잡한 장면 몇 개를 캡처해서 보여 줘. 글자가 겹치거나 잘리는 곳이 없는지도 확인해 줘.
